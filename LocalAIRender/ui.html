文本/多模态分析通道

用于白模总结、Pinterest 搜索词规划、灵感图反推。mimo-v2.5、gpt-5.5 这类模型都填在这里；如果模型不支持图片，会自动文本降级并继续生成。

备用分析接口

当主分析接口或主模型失败时，会按顺序尝试这里的接口，并组合上方“白模总结模型/灵感反推模型/备用模型池”。每行一个接口；Key 可留空表示沿用主分析 Key。

GitHub 更新

更新会先备份当前插件，再从 GitHub 下载发布包覆盖本机插件目录。Ruby 代码需要重启 SketchUp 才会生效。

帮助中心

SU 本地 AI 渲染工作流

这个版本保留一个生图入口，默认使用 fucheers 渠道的 gpt-image-2。先获取模型截图或选择相机视角，再输入描述并生成；结果会自动保存到本地历史，重新打开插件也能继续使用。

基础生成

点击“获取模型截图”使用当前视角，或点击“获取相机视角”从 SketchUp 场景中选择视图。不写提示词时会自动补写实渲染提示词。

结果操作

结果图悬停后可设为参考图、去改图、高清放大、下载、删除。去改图会把结果图变成新的输入图，并聚焦到描述框。

历史成果

每次成功生成会保存到输出目录的 history_images 和 history.json。重开插件会恢复最近成果，也可以在历史列表中切换。

常见错误

403 通常是模型权限问题；400 多半是参数或提示词问题；500 multipart 解析错误通常说明请求格式不匹配。当前默认已固定为 gpt-image-2 和 Multipart。
